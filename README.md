# Varsha Bhatt — QA Engineer Portfolio

Personal portfolio site built with Next.js, implemented from a Claude Design wireframe, with scroll-driven animations (Motion + Lenis).

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Structure

- `src/lib/data.ts` — all site content (stats, skills, projects, contact links)
- `src/components/` — page sections (Hero, Metrics, Skills, Projects, Experience, Contact) and shared animation primitives (`motion.tsx`)
- `media/` — profile photo
- `public/` — downloadable resume PDF
